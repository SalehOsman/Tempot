## نظرة عامة

إدارة المعرفة هي لوحة المدير العام لبناء فهارس معرفة البوت. تستخدم المساعدة
الذكية هذه الفهارس للإجابة عن أسئلة التوثيق مع عرض المصادر.

## مصادر المعرفة

يمكن للبوت بناء فهارس معرفة مستقلة للمصادر التالية:

| المصدر | الغرض |
| ------ | ----- |
| Product | توثيق المنتج ودليل المستخدم والموديولات من منظور المستخدم |
| Operations | أدلة التشغيل والطوارئ والأدلة العملية للنشر والاسترجاع |
| Architecture | قرارات المعمارية وتصميم النظام |
| Analysis | تقارير تحليل المشروع والمراجعات السابقة |
| Full Project | فهرسة واسعة للتوثيق والمواصفات والباكيدجات والموديولات |
| Custom | مصدر مخصص باسم ومسار يحدده المدير العام |

لأسئلة الاستخدام اليومية يجب بناء مصدر Product أولًا. أما أسئلة التشغيل
والاسترجاع فتحتاج غالبًا إلى بناء Operations، وأسئلة التصميم تحتاج Architecture.

## بناء فهرس المعرفة

لبناء المعرفة:

1. افتح القائمة الرئيسية باستخدام `/start`.
2. افتح قائمة المعرفة.
3. اختر المصادر.
4. اختر المصدر المطلوب بناؤه.
5. شغل Dry run للتأكد من أن المصدر يمكن فحصه بأمان.
6. شغل Write index لكتابة التضمينات الخاصة بالمصدر المحدد.
7. انتظر رسالة اكتمال العملية.

مسار الكتابة الحالي داخل البوت ينفذ تقديرًا آمنًا قبل الكتابة ويمنع المصادر
التي تتجاوز حد عدد المقاطع المضبوط. يظهر Full reindex في القائمة، لكن المسار
الحالي يبلّغ المستخدم بأنه مخطط ولم يتم تفعيله كتنفيذ مباشر.

يعتمد البناء على مزود التضمينات المضبوط حاليًا. يمكن استخدام Ollama محليًا
للفهرسة المجانية عند ضبط `AI_EMBEDDING_PROVIDER=ollama` و`OLLAMA_BASE_URL` على
خدمة Ollama المحلية.

## طرح الأسئلة

يمكن للمستخدم طرح الأسئلة عبر زر المساعدة الذكية أو عبر إرسال السؤال بعد
`/ask` أو `ask/` أو `ask` أو صيغة السؤال العربية. إجراء Test query داخل قائمة
المعرفة يوجه المستخدم حاليًا إلى استخدام `/ask` لاختبار الاسترجاع.

إذا ظهرت رسالة تفيد بعدم وجود سياق موثوق، أعد بناء المصدر المناسب. أسئلة
استخدام البوت تعتمد غالبًا على Product، وأسئلة الاسترجاع والطوارئ تعتمد غالبًا
على Operations.
