## نظرة عامة

تمبوت هو قالب بوت تيليجرام مؤسسي. يوفر البوت قوائم تفاعلية للمستخدمين
والمديرين والمدير العام. تختلف الإمكانيات المتاحة حسب دور المستخدم وحسب
الموديولات المفعلة.

## الإمكانيات الرئيسية

يدعم البوت حاليًا:

- عرض الملف الشخصي ومعلومات الحساب.
- تغيير اللغة والإعدادات الشخصية.
- تقديم طلب عضوية والموافقة عليه.
- إدارة المستخدمين بواسطة المديرين، مع حماية إدارة الأدوار والحظر بصلاحيات أعلى.
- عرض الإشعارات وإرسال إشعار تجريبي.
- إنشاء نسخة احتياطية، عرض سجل النسخ، فحص الاسترجاع، الاسترجاع الفعلي، وإعادة التهيئة.
- بناء فهرس المعرفة وطرح أسئلة ذكية على توثيقات المشروع.
- عرض المساعدة واكتشاف الأوامر المتاحة.

## الأدوار

يعتمد البوت على أربعة مستويات صلاحيات:

| الدور      | الوصول المعتاد |
| ---------- | -------------- |
| زائر       | يمكنه طلب العضوية إذا لم يكن محظورًا |
| مستخدم     | يستخدم الملف الشخصي والإعدادات والرسائل والمساعدة |
| مدير       | يدير الأجزاء التشغيلية المفوضة، بما في ذلك إدارة المستخدمين عند توفر الصلاحية |
| مدير عام   | يدير الأدوار والمستخدمين المحظورين والنسخ الاحتياطي والمعرفة |

المستخدم المحظور لا يستطيع استخدام مزايا البوت أو تقديم طلب عضوية حتى يتم فك
الحظر بواسطة المدير العام.

## طريقة الاستخدام

الاستخدام الأساسي يتم من خلال الأزرار التفاعلية. ما زالت الأوامر النصية مدعومة
لإجراءات مثل `/start` و`/help` و`/ask`.

لطرح سؤال على المساعدة الذكية يمكن استخدام زر طرح سؤال أو إرسال السؤال بعد
`/ask` أو `ask/` أو `ask` أو صيغة السؤال العربية.
